# 프롬프트 토글 v1.1.0

실리태번 채팅 입력창 왼쪽 **마법봉 → 프롬프트 토글**에서 여러 공통 지시문을 관리합니다.

## 기존 GitHub 저장소 업데이트

1. ZIP을 풀고 `st-global-prompt-toggle` 폴더 **안의 파일 8개**를 선택합니다.
2. 기존 `hy264b-hub/prompt-toggle` 저장소의 **Add file → Upload files**에서 같은 위치에 올리고 Commit changes로 저장합니다. `manifest.json`과 `core.js`가 저장소 첫 화면에 바로 보여야 합니다.
3. 실리태번 **확장 관리 → 해당 확장 업데이트**를 실행하고 브라우저를 새로고침합니다. 이전 화면이 남으면 강력 새로고침(Ctrl+F5)을 사용하세요.
4. 마법봉 메뉴에서 **프롬프트 토글**을 엽니다. 기존 확장을 삭제하거나 설정을 초기화할 필요는 없습니다.

이번 버전에는 **core.js가 추가**되었습니다. index.js만 바꾸면 실행되지 않습니다. 같은 확장을 다른 이름으로 중복 설치하지 마세요.

## 처음 설치

실리태번 **확장 → 확장 설치**에 이 코드가 올라간 GitHub 저장소 주소를 넣습니다.
수동 설치는 압축을 푼 폴더를 `SillyTavern/data/<사용자 핸들>/extensions/` 안에 넣고 다시 실행하면 됩니다. 기본 사용자 경로는 보통 `data/default-user/extensions/`이며, 사용자 데이터 경로를 변경했다면 그 위치를 사용합니다.

## 사용

- **+ 지시문 추가**: 이름과 내용을 입력합니다. 새 항목은 OFF로 시작합니다.
- **항목별 적용**: 여러 지시문을 동시에 켤 수 있습니다. 내용이 빈 항목은 제외합니다.
- **항목 이름 클릭**: 해당 항목의 내용과 삽입 위치·역할을 펼칩니다.
- **삽입 위치**: 마지막 메시지 뒤(Depth 0), 앞(Depth 1), 직접 지정(0~10000).
- **역할**: System / User / Assistant.
- **↑ / ↓**: 목록 순서를 변경합니다. 같은 Depth·역할의 항목은 이 순서대로 합쳐서 전달합니다. 서로 다른 Depth·역할 간 최종 배치 순서는 실리태번이 결정합니다.
- **복제**: 같은 내용의 항목을 만들되, 중복 적용을 막기 위해 복사본은 OFF로 둡니다.
- **삭제 / 방금 삭제한 지시문 복원**: 마지막으로 삭제한 항목 하나를 창을 닫아도 같은 페이지 세션에서 복원할 수 있습니다. 새로고침하면 복원 기록은 사라집니다.
- **전체 적용**: 모든 지시문 적용을 잠시 끕니다. 각 항목의 ON/OFF 상태는 유지합니다.
- **변경사항 자동 저장**: 현재 실리태번 사용자 계정에 저장합니다. 프리셋·캐릭터·채팅을 바꿔도 유지합니다. 수정 직후에는 잠깐 기다린 뒤 브라우저를 닫으세요.

## 기존 설정 이전

v1.0.0의 지시문은 **기존 지시문**이라는 첫 번째 항목으로 자동 이전합니다. 내용, ON/OFF, 삽입 위치, 역할을 유지하며 이전 설정 원본도 내부에 보관합니다. 새 기능의 ‘전체 적용’은 ON으로 시작하고, 실제 적용 여부는 이전한 항목의 기존 ON/OFF에 따릅니다.

## 적용 범위와 확인

일반 답변·재생성·스와이프·이어쓰기·사용자 대리 생성에 적용합니다. Quiet 백그라운드 생성은 기본 제외하며 하단 설정에서 포함할 수 있습니다. 실리태번의 일반 생성 경로를 거치지 않는 다른 확장의 직접 API 호출까지 적용하지는 않습니다.

Depth는 대화 기록 기준입니다. 프리셋의 Post-History Instructions가 더 뒤에 올 수 있고, API·메시지 후처리 설정에 따라 실제 전송 형태가 바뀔 수 있습니다. 너무 큰 깊이는 대화 길이를 고려해 사용하세요.
OFF는 이전 대화나 이미 생성된 답변을 지우지 않습니다. 기존 프리셋에 같은 문구가 있다면 해당 항목은 별도로 꺼주세요.

답변 생성 후 **Prompt Itemization / Prompt Inspector**에서 실제 포함 여부를 확인하세요. 프롬프트 포함과 모델의 지시 이행은 별개입니다.

## 검증

JavaScript 구문 검사, 모의 호스트 기반 핵심 동작 검사, DOM 시뮬레이션으로 메뉴·목록 조작 검사를 수행했습니다. 실제 실리태번 및 연결 모델 통합 검사와 브라우저 시각 검사는 미실시입니다. `VALIDATION.md`에 범위를 기록했습니다.

개발용 핵심 검사: `node test-core.cjs` (추가 패키지 불필요).
