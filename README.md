# 공통 프롬프트 토글 v1.0.0

추가 지시문을 한 번 저장하고 ON/OFF로 관리하는 SillyTavern 확장입니다.
설정은 현재 실리태번 사용자 계정에 저장되며 프리셋·캐릭터·채팅을 바꿔도 유지됩니다.

## 설치

1. 실리태번을 종료합니다.
2. ZIP을 풀어 `st-global-prompt-toggle` 폴더를 꺼냅니다.
3. 실리태번 설치 폴더의 `data/<사용자 핸들>/extensions/` 안에 넣습니다. 기본 사용자라면 보통 `data/default-user/extensions/`입니다. 사용자 데이터 위치를 따로 지정했다면 그 위치를 사용하세요.
4. 최종 구조가 `data/default-user/extensions/st-global-prompt-toggle/manifest.json`인지 확인합니다. 같은 이름의 폴더가 두 번 겹치지 않게 해주세요.
5. 실리태번을 다시 실행하고 브라우저를 새로고침합니다.
6. 상단 확장 메뉴(퍼즐 아이콘)에서 **공통 프롬프트 토글** 설정을 엽니다. 확장 관리에서 비활성화되어 있다면 활성화합니다.

이 ZIP은 폴더 복사로 설치하는 배포본입니다. ‘확장 설치’ URL 입력란에는 ZIP 경로나 이 다운로드 링크를 넣지 마세요. URL 설치에는 별도의 Git 저장소가 필요합니다.
호스팅 서비스를 이용해 설치 폴더에 접근할 수 없다면 해당 서비스의 확장 설치 방식을 확인해야 합니다.

## 사용

1. 지시문 입력란에 원하는 내용을 작성합니다. 입력과 설정 변경은 실리태번의 자동 저장 기능을 사용합니다. 수정 직후에는 잠깐 기다린 뒤 창을 닫으세요.
2. 삽입 위치를 고릅니다.
3. **추가 지시문 적용**을 켭니다. 이후 생성 요청부터 반영됩니다. 진행 중인 요청에는 소급 적용되지 않습니다.
4. 끄면 이후 요청에 이 확장의 지시문을 추가하지 않습니다. 입력한 내용은 유지됩니다.

| 삽입 위치 | 의미 |
| --- | --- |
| 마지막 메시지 뒤 | Depth 0, 대화 기록 끝 |
| 마지막 메시지 앞 | Depth 1, 마지막 메시지 바로 앞 |
| 직접 지정 | Depth 0~10000. 숫자가 커질수록 과거 메시지 쪽 |

Depth는 사용자+AI 한 쌍이 아니라 메시지를 기준으로 합니다. 대화 길이에 비해 너무 큰 깊이의 배치는 실리태번의 프롬프트 구성 처리에 따르므로 작은 값부터 사용하세요.
위치는 **대화 기록 기준**입니다. Post-History Instructions나 다른 확장의 지시문이 더 뒤에 올 수 있습니다. 전체 프롬프트의 마지막을 보장하지 않습니다.

고급 설정에서 System / User / Assistant 역할을 선택할 수 있습니다. 기본은 System입니다. API 종류와 실리태번의 메시지 후처리 설정에 따라 최종 전달 형식은 달라질 수 있습니다.
일반 답변·재생성·스와이프·이어쓰기·사용자 대리 생성에 적용됩니다. Quiet 백그라운드 생성은 기본 제외하며 고급 설정에서 포함할 수 있습니다. 일반 생성 경로를 거치지 않고 다른 확장이 API를 직접 호출하는 경우까지 적용하지는 않습니다.

## 적용 확인

- **추가 지시문 확인**은 저장된 지시문과 위치·역할을 보여주는 미리보기입니다. 실제 전체 요청이나 매크로 치환 결과는 아닙니다.
- 실제 확인은 답변 생성 후 실리태번의 Prompt Itemization 또는 Prompt Inspector에서 수행하세요. 고유한 문장을 넣고 ON/OFF 각각 생성하여 포함 여부를 비교하면 됩니다.
- 프롬프트 포함 여부와 모델의 지시 이행은 다릅니다. 기존 지시문과 충돌하면 원하는 출력이 나오지 않을 수 있습니다.
- OFF는 기존 대화나 이전 답변을 지우지 않습니다. 이전 출력이 문맥에 남아 영향을 줄 수 있습니다.
- 같은 지시문을 기존 프리셋에도 넣었다면 그 항목은 따로 꺼주세요. 이 확장은 기존 프리셋의 중복 문구를 삭제하지 않습니다.

## 호환성과 검증

공식 release 소스의 `SillyTavern.getContext()`, `setExtensionPrompt`, `extensionSettings`, `saveSettingsDebounced` 및 생성 이벤트·인터셉터를 기준으로 작성했습니다. 추가 서버 플러그인과 별도의 빌드 과정은 필요 없습니다.
실제 사용자 실리태번 설치 및 연결된 모델로 수행하는 통합 테스트는 아직 하지 않았습니다. 사용 중인 버전의 API와 연결 방식에 따라 확인이 필요합니다.
검증 내역은 `VALIDATION.md`를 참고하세요.
